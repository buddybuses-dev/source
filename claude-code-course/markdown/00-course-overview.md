# Claude Code for Beginners
### Getting real work out of an AI agent, starting from zero

**Course version:** 1.0 (July 2026)
**Author:** Jared Hebb
**Format:** 8 self-paced modules, about 6 hours total, text lessons with hands-on exercises
**Also works as:** a 1-day or 2-evening in-person workshop (see the Instructor Guide)

---

## Who this course is for

People who keep hearing about AI coding agents and want to actually use one. Small business owners. Freelancers. Analysts. Students. You do not need to be a programmer. I'm not one, and I wrote the course. Developers new to Claude Code will move faster through the early modules but still get their money's worth from Modules 5 through 7.

**What you need:** a computer running Windows, Mac, or Linux, the willingness to type into a terminal, and a paid Claude plan. Pro is about $20 a month and includes Claude Code. That's the whole shopping list.

## What you'll be able to do by the end

1. Install and run Claude Code on your own machine
2. Run a productive working session: give clear instructions, review what Claude did, correct course when needed
3. Use Claude Code for everyday non-coding work: organizing files, processing data, drafting documents, automating repetitive tasks
4. Build and publish a real, live website with no coding experience
5. Use git and GitHub through Claude Code without memorizing a single command
6. Customize Claude Code with a CLAUDE.md file, slash commands, and permission settings that match your comfort level
7. Undo anything. Nothing you break stays broken.

## How to take this course

Do the exercises. All of them. Here's the truth about courses: reading feels like progress and produces nothing. Every module ends with hands-on work, and the exercises are where the actual learning lives. Reading teaches you *about* Claude Code. The exercises teach you Claude Code. Those are different products, and only one of them was worth paying for.

Use your own real files and problems wherever an exercise allows it. My examples make the course make sense. Your problems make it pay.

Keep the cheat sheet open (`cheatsheet.md`). One page, everything in the course.

Stuck? Ask Claude Code itself. "Explain what just happened" is a completely legitimate move, and Module 3 teaches you to use it.

## What this course is not

It's not a programming course. You'll ship working code without reading much of it. Module 1 explains why that's fine for beginners and exactly where the limits are.

It's not a bag of prompt tricks. Tricks expire. The skill you're building is delegation: scoping work, reviewing results, iterating. Delegation doesn't expire.

It's not tied to one version of Claude Code. The tool updates constantly, so the course teaches what stays stable and points you to `/help` and the official docs for what changes fast.
