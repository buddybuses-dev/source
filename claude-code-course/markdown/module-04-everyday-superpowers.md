# Module 4: Everyday Superpowers (No Code Required)

**Time:** about 60 minutes. **Hands-on:** five guided mini-projects.

## Objectives

- Recognize the five kinds of tasks where Claude Code pays for itself immediately
- Complete one hands-on task in each category
- Start noticing, during your normal week, "wait, this is a Claude Code task"

---

This is the module that pays for the course, so let's be clear about the unlock. It isn't a skill. It's recognition. The tool can already do the work. The bottleneck is that most people never notice the tedious thing they're doing by hand could be delegated. They just... keep doing it. For years. This module installs the noticing reflex, using five task families.

## 4.1 Family 1: File wrangling

Anything involving lots of files: renaming, sorting, deduplicating, converting formats, restructuring folders.

**Mini-project A: tame a messy folder.** Launch Claude Code in your Downloads folder (or a copy of it) and run:

> "Organize this folder: create subfolders by file type (Documents, Images, Installers, Archives, Other) and move files accordingly. Within Documents, make year subfolders based on each file's modified date. Show me the plan and move 10 files as a sample before doing the rest. Don't delete anything."

Notice the safety habits baked into the brief: an explicit "don't delete anything," and a sample before the full run. That's not paranoia. That's how you get to be bold cheaply.

## 4.2 Family 2: Data and spreadsheets

CSVs, Excel exports, merging sheets, cleaning inconsistent data, computing summaries, making charts. Claude Code handles these with real tools. Under the hood it quietly uses Python or similar, and you never have to care.

**Mini-project B: clean and summarize.** Get any CSV. A bank export or a sales report works, or ask Claude to generate a realistic messy sample CSV of 500 fake orders. Then:

> "Clean this CSV: standardize the date format, trim whitespace, and flag duplicate rows in a new column rather than deleting them. Then give me a summary: totals by month, top 5 categories, and anything weird you noticed. Save the cleaned file separately. Never overwrite the original."

The phrase "anything weird you noticed" earns its keep every time. Agents catch anomalies humans skim past. It's five words. Use them.

## 4.3 Family 3: Documents and writing

Drafting from bullet points, reformatting, merging documents, generating variations (say, 12 personalized versions of one letter), extracting information from PDFs.

**Mini-project C: mail merge without Mail Merge.** Create a small CSV of 5 names and companies (or have Claude invent them), plus a paragraph describing something you're offering. Then:

> "Using contacts.csv and my offer description in offer.txt, draft a personalized outreach email for each contact as separate .txt files. The audience is small-business owners, so keep it warm and direct, no jargon, under 150 words each."

Review one closely, give tone feedback ("less salesy, more neighborly"), and have it regenerate all five. Burn that loop into your brain: **edit one, apply to all.** It's the difference between fixing a letter and fixing a system.

## 4.4 Family 4: Research and synthesis

Claude Code can search the web, read pages, and pull what it finds into a document. Useful when the output should be a file you keep, not a chat answer that scrolls away.

**Mini-project D: a comparison table.** Pick a real decision you're facing (accounting software, a standing desk, a CRM):

> "Research the top 4 options for [your decision] for [your situation]. Build me a comparison table in a markdown file: price, key features, the main complaint from real users, and who each one is best for. Include links to sources so I can check the claims."

Straight talk on verification: research is the family where confident-but-wrong answers are most likely. The "include links" line isn't decoration. Spot-check any claim that would actually change your decision. Trust the table for orientation. Verify it for commitment.

## 4.5 Family 5: Repetitive workflows become tools

The graduation move. When you notice you'll want a task again, don't plan to re-ask. Ask Claude to turn it into a reusable script you run without thinking.

**Mini-project E: your first tool.** Take the Downloads-organizing task from 4.1:

> "Turn the folder organizing we just did into a script I can re-run anytime. I'm on [Windows/Mac]. Make it something I can double-click, and have it print a summary of what it moved."

Read that outcome again: you now own software you didn't write. It cost you a sentence. When it needs a tweak next month, launch Claude Code and ask for the tweak. This is the pattern that turns a $49 course into hours back every week.

## 4.6 The recognition checklist

You probably have a Claude Code task on your hands when the work is:

- Repetitive (the same action across many items)
- Format-shifting (this file type into that file type, this layout into that layout)
- Rule-based tedium ("if X, put it in Y," a hundred times over)
- Synthesis (many sources condensed into one document or table)
- Something you'd do if it took 5 minutes, but keep skipping because it would take an hour by hand

That last one is the money category. Everyone has those tasks. Add yours up: three hours a week is 150 hours a year. Put this list somewhere you'll see it for two weeks. The reflex forms fast, and once it forms, it compounds.
