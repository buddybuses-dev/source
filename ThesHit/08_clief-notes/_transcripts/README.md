# Clief Notes — rå video-transkripsjoner

Auto-genererte YouTube-tekstinger (`yt-dlp --write-auto-sub`) for de 21 Clief Notes-leksjonene
som har en video. Renset til ren tekst (tidsstempler + `<c>`-tagger fjernet, dedupet).

**Formål:** kildegrunnlag for «## Fra videoen»-seksjonene i kortene. Kortene inneholder
omskrevne norske sammendrag; disse filene er de ordrette transkripsjonene.

**`00-video-id-map.txt`** — mapping leksjon → YouTube-video-ID.

## Opphavsrett

Dette er ordrett transkribert innhold fra Jake Van Cliefs Skool-kurs (gratis-nivå). Ligger her
kun som lokalt arbeidsmateriale. **Skal ikke pushes / distribueres.** Se `.gitignore`.
