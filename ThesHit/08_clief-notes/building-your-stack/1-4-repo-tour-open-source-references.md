# 1.4 Repo Tour: Open Source References

Kilde: https://www.skool.com/cliefnotes/classroom/2a86a1d1?md=43bfcb21546841eb840ab66e80c0b3ec

**Kuratert liste over open-source AI-UI-prosjekter verdt å studere, med notater om hva man
kan lære av hver.** Ikke en tutorial — en research-ressurs. Noen wrapper Claude Code, noen
bygger custom chat-UI-er, noen løser problemer du ikke har tenkt på. Per repo: hva det gjør /
hva som er verdt å studere / hva du kan låne. Eksempel: «Claude Code Web» (web-frontend for
Claude Code) — studer session-persistens og websocket-koblingen mellom frontend og Claude
Code CLI. Klon bare de relevante for det du bygger. Siden oppdateres når nye repoer dukker opp.
Kobling til vår `caveman/CATALOG.md` + `rooms/learning/tools.md`.
