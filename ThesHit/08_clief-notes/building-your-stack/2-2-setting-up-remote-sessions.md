# 2.2 Setting Up Remote Sessions

Kilde: https://www.skool.com/cliefnotes/classroom/2a86a1d1?md=f305a93c1be949d3b3bcdbc2aa22a3f5

**Tre måter å starte Remote Control på:**
- **Server Mode** — `claude remote-control` (kort: `claude rc`). Remote-only; terminalen viser
  tilkoblingsstatus, du styrer fra telefon/nettleser. Terminalen viser session-URL + QR-kode
  (mellomrom for å toggle QR).
- **Interactive + Remote** — `claude --remote-control` (kort: `claude --rc`). Normal økt som
  også er tilgjengelig eksternt; du kan skrive i terminalen OG styre fra telefonen, synkronisert.
- **Enable Mid-Session** — `/remote-control` (kort: `/rc`) i en pågående økt.
