# 4.4 Making Claude Understand Your Project

Kilde: https://www.skool.com/cliefnotes/classroom/036893d9?md=f0655889bd8c49b0a99f5afb9eb03229

**Skriv en `CLAUDE.md` som får Claude Code til å oppføre seg som om den har vært på prosjektet
en måned. Én fil, ti minutter, umiddelbar forskjell.** Problemet: Claude Code kjenner ikke
konvensjonene dine, filstrukturen, hvilke bibliotek du bruker, hvilke kommandoer som skal
kjøres, eller hva du regner som godt arbeid — hver nye samtale er en «smart fremmed» som
gjetter på ting et teammedlem allerede ville visst. Fiksen: én markdown-fil i prosjektroten
som Claude Code leser automatisk. (Video merket «Coming Soon»; skriftlig leksjon finnes.)
= nøyaktig hva `CLAUDE.md` i `first system project` gjør.
