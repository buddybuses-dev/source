# LESSON 3.4: Computational Orchestration

Kilde: https://www.skool.com/cliefnotes/classroom/d7ae60cf?md=ed8f01da061a4b76bfde21fc4dbd4d41

**Disiplinen som vokste fram av hele kurset — og som `first system project` allerede
praktiserer, nå satt på navn.** Ikke *hvordan* bruke AI, men *å vite når*: når AI, når
tradisjonell kode, når holde et menneske i loopen. Tidlige versjoner: «coding pyramid»
(maskinkode nederst, Python i midten, LLM-er øverst — hvert lag lar en novise gjøre det som
før krevde en ekspert) og «THINK»-akronymet for akademisk skriving.

Nå heter det **computational orchestration**: disiplinen å vite hvilken type beregning som
skal på hvilket problem — **tradisjonell kode for de deterministiske delene, språkmodeller
for de semantiske delene, mennesker for skjønnsvurderingene** — og viktigst: å vite når man
IKKE skal bruke AI. = nøyaktig METHOD.md steg 5 + VERIFICATION.md + evig checkpoint hos oss.
