# 2.4 Inbox and Scheduling on Autopilot

Kilde: https://www.skool.com/cliefnotes/classroom/d3907117?md=37e80918f9794f0fb8696315d0e7912a

**E-post-triage og kalenderstyring på minutter i stedet for timer, med tydelige guardrails
så ingenting går galt.** Steg: åpne Gmail (`mail.google.com`) + Claude-sidebaren → «Summarize
my unread emails» (Claude skanner synlige e-poster, gir kategorisert oppsummering på sekunder;
du kan bytte fane mens den jobber) → bli mer spesifikk («Are there any emails that need a
response today?»). Guardrail: «Ask before acting» slik at Claude ikke sender/sletter uten
godkjenning. Samme prinsipp som `operations/`-innboks-jobben + evig checkpoint på ekstern melding.
