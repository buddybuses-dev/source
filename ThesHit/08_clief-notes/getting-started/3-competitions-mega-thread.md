# Competitions Mega Thread

Kilde: https://www.skool.com/cliefnotes/classroom/f3fc312c?md=e3b24a29ab7247b8a16d253dd17b3e47

**Én samlet tråd for alle community-konkurranser.** To spor: (1) **biweekly challenges**
(temabaserte bygg-oppgaver, f.eks. «The Operator» — en agent som kjører en salgspipeline),
(2) **weekly leaderboard** der den som topper den 7-dagers rullerende leaderboarden vinner en
gratis medlemskaps-oppgradering, annonsert mandager. Konkurransene handler om å faktisk bygge
noe som virker og vise en demo.

**Kategori:** Getting Started
