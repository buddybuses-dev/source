# A completely markdown based task management system

Kilde: https://www.skool.com/cliefnotes/classroom/c7f102c7?md=c223dac9bc604d93bf46a70ac2795278

**Verktøy / oppsett (Roc Lee).** Et fullt oppgavestyrings-system bygget helt i markdown-filer: synkes på tvers av maskiner via terminal-hooks, bruker AI til å prioritere dagen, og virker offline. Poeng: hvis oppgave-systemet ditt bor i en proprietær app, kan ikke AI-en lese det — ren tekst gir både deg og verktøyene full tilgang. Davids ramme: «dette skjer når noen tar 'mappa di er operativsystemet' på alvor» — ren tekst, git-synket, AI-lesbar; capture-til-prioritér-sløyfen er det smarte. GitHub-repo inkludert for fork.

**Relevans for oss:** nesten identisk med `operations/` + `plan/PLAN.md` «Neste steg» + `scripts/autoplan.py`. «Terminal-hooks for sync» = kandidat til `.claude/settings.json` hooks. Verdt å sammenligne mot vårt oppsett for å hente capture-loopen. Kobler til [`remember-tasks-between-sessions.md`](remember-tasks-between-sessions.md).
