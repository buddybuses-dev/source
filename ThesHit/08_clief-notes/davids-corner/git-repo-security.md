# Git Repo Security: Why It Matters

Kilde: https://www.skool.com/cliefnotes/classroom/c7f102c7?md=43a45577d5cb4096b040770491d87b50

**Hvorfor git-repo-sikkerhet betyr noe når man vibe-coder / kjører agenter mot et repo:**
hemmeligheter/nøkler som havner i historikken, `.gitignore`-hull, tokens i klartekst,
offentlige repoer med sensitivt innhold. Direkte relevant for `first system project`:
`rooms/git/reference.md`, `.gitignore`-mønstrene (`*.env`, `**/*token*`, `**/*secret*`,
`**/*credentials*`), `security/CANARY-TOKENS.md` og hele canary-arbeidet.
