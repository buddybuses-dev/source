# I run four phases before any AI builds anything

Kilde: https://www.skool.com/cliefnotes/classroom/c7f102c7?md=a0750a06c782450385b326a04a95a2f9

**Fire-fase planleggingsmetodikk (av Ari Evergreen): `Brainstorm → Plan → Hand off Doc →
Dispatch`** — front-loader all tenkning før AI genererer kode eller innhold. «Hopper du over
strukturert planlegging og går rett på prompting, bruker du 90 % av tiden på å passe outputs
i stedet for å få rene resultater på første forsøk.» Davids notat: «bygget er den enkle
delen, tenkningen er arbeidet — dette beviser hvorfor `CONTEXT.md` og spec-docs finnes. Får
du søppel-outputs, er fiksen oppstrøms.» = `first system project` sin `/plan` + METHOD.md
(«prosess først, så automasjon») + `operations/DISPATCH.md`.
