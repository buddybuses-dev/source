# This one's golden... Vibe coding rules

Kilde: https://www.skool.com/cliefnotes/classroom/c7f102c7?md=e25f0b3971344ec1a12cf9db523b679a

**`vibe-code-rules.md` av @Noah Taylor — én sannhetskilde for beste praksis på tvers av
vibe-coding-prosjekter.** Lettvekt, repeterbare regler som «holder slop ut og konsistens
inn». Ikke produksjons-evangelium eller et oppblåst rammeverk — den typen praktisk, no-fluff
guardrail de fleste som grinder agentiske arbeidsflyter faktisk trenger. Hovedpoeng:
**behandler filsystemet som arkitekturen (mapper + markdown gjør tungløftet)**, tydelig skille
mellom vibe-coding-prosjekter og alt annet, ærlig amatør-perspektiv med innebygd oppfordring
til tilbakemelding fra mer erfarne. «Save it. Use it. Improve it.»
