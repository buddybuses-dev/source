# 4.2 Claude Code in Practice

Kilde: https://www.skool.com/cliefnotes/classroom/036893d9?md=6ccef7306c3c4ba29373f018a75e0748

**Modul 4, leksjon 2 (video «Coming Soon» — companion-tekst er kjøttet).** Hva som gjør Claude Code forskjellig fra chat-grensesnittet: **den er ikke smartere enn Claude Desktop — det er samme modell.** Forskjellen er hva den *når* — den kan se arbeidet ditt, ta på filene dine, og iterere på egen output. Sløyfen: **Read → Think → Write → Check → Adjust.** I chat kjører den sløyfen én gang og stopper; i Claude Code kjører den til jobben er gjort. Eksempel som viser forskjellen: 15 møtenotater, du vil ha alle beslutninger tatt dette kvartalet, organisert per prosjekt — i Desktop åpner du fil 1, kopierer, limer... i Code leser den alle 15 og leverer.

**Relevans for oss:** «Read → Think → Write → Check → Adjust til jobben er gjort» er nøyaktig hvordan denne sesjonen jobber mot `first system project`. Møtenotat-eksempelet = `operations/monitoring/INBOX`-jobben. Kobler til METHOD.md og `VERIFICATION.md` (Check-steget).
