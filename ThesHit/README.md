# ThesHit - The Faction: Free AI Engineering Curriculum (personal workspace)

Mirrors the structure of https://the-faction.mn.co - one folder per space,
one sub-folder per layer / course / module, each with a study-guide, exam and notes file.

## Map
- 00_start-here         -> Welcome To The Faction
- 01_the-foundation     -> The Foundation (13 layers)
- 02_the-mastery        -> The Mastery (7 courses x 7 modules)
- 03_the-industry       -> The Industry (3 verticals x 7 modules)
- 04_the-vault          -> The Vault (3 courses x 7 modules)
- 05_the-launchpad      -> The Launchpad (3 courses x 7 modules)
- 06_the-frontier       -> The Frontier (3 courses x 7 modules)
- 07_community          -> The Pit / The Mentoring Lounge / The Forge
- _templates            -> reusable study-guide / exam / ship templates
- _resources            -> The Forge: frameworks, reference, tools, case studies
- badges.md             -> recognition system: Deploy, Cosign, Operate, Build, Recruit
- progress-tracker.md   -> master checklist
