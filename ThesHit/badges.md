# Recognition Badges (Leaderboard)

Members recognise each other in these five categories. Each has its own leaderboard,
refreshed weekly.

## Deploy
Shipping work to production.

## Cosign
Vouching for / endorsing another builder's work.

## Operate
Running and maintaining live systems.

## Build
Building - work in progress, frameworks, components.

## Recruit
Bringing new builders into the community.
